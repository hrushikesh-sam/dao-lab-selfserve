Pass the internal secret to playbooks in a 0600 file (F-5-1)

What: the runner passed DAOLAB_INTERNAL_SECRET to the playbooks as an
extra var, and ansible-runner writes extra vars to
job-<id>/<run>/env/extravars, so every job dir kept the secret on disk.
The runner now writes the secret to a new 0600 file (mkstemp) in
DAOLAB_RUNTIME_DIR, or in systemd's RUNTIME_DIRECTORY tmpfs in
production. It passes only the path, as daolab_internal_secret_file,
and removes the file when the run ends. Stale files left by a SIGKILLed
run are swept. playbooks/group_vars/all.yml reads the secret from the
file, and every use is no_log: true.

Why: on the controller laptop, 1563 files under var/showcase-jobs held
the secret (23 of them env/extravars). The leaked secret was rotated and
all old copies deleted on 2026-11-23.

service/runner.py, tests/test_ansible_runner.py,
tests/test_runner_secret.py (new).
